PART 0 — Postman setup (do once)

  1. Install Postman from postman.com/downloads and open it.
  2. Environments → + → name LMS API → add baseUrl = http://localhost:8000 and token = empty → Save. Select it top-right.
  3. Collections → New Collection LMS → Authorization tab → Type Bearer Token → Token {{token}} → Save.
  4. Every request goes inside LMS, URL starts with {{baseUrl}}.
  5. Sending data? Click Body → raw → JSON, paste, click Send.

PART A — Account

A1. Register (create account) Public

  1. POST {{baseUrl}}/api/v1/auth/register, Body → JSON: 
    { "name": "Test Student", "email": "student@example.com", "password": "Pass@123" }
  2. Send. Copy activationToken + activationCode (6 digits, dies in 5 min). Reply is 201; if mail is down you still get the code with mailSent:false.

A2. Activate Public

  1. POST {{baseUrl}}/api/v1/auth/activate-user, Body → JSON: 
    { "activation_token": "PASTE_LONG_TOKEN", "activation_code": "PASTE_6_DIGITS" }
  2. Good reply: User activated successfully.

A3. Login (get your key) Public

  1. POST {{baseUrl}}/api/v1/auth/login, Body → JSON: 
    { "email": "student@example.com", "password": "Pass@123" }
  2. Copy accessToken → paste into environment token → Save. Or put this in the Tests tab to auto-save: 
    const j = pm.response.json();
pm.environment.set("token", j.accessToken);

A4. My profile Login — GET {{baseUrl}}/api/v1/auth/me

A5. Logout Login — GET {{baseUrl}}/api/v1/auth/logout, then clear token

A6. Refresh key — GET {{baseUrl}}/api/v1/auth/refreshtoken (or just login again)

A7. Google login Public — POST {{baseUrl}}/api/v1/auth/social-auth: 
{ "email": "me@gmail.com", "name": "Me" }

A8. Change name Login — PUT {{baseUrl}}/api/v1/auth/update-user-info: 
{ "name": "New Name" }

A9. Change password Login — PUT {{baseUrl}}/api/v1/auth/update-user-password: 
{ "oldPassword": "Pass@123", "newPassword": "NewPass@456" }

A10. Change photo Login — PUT {{baseUrl}}/api/v1/auth/update-user-profile-picture: 
{ "avatar": "PASTE_IMAGE_LINK" }

A11. All users Admin — GET {{baseUrl}}/api/v1/auth/get-all-user-dashboard

A12. Make admin Admin — PUT {{baseUrl}}/api/v1/auth/update-user-roles: 
{ "id": "PASTE_USER_ID", "role": "admin" }
That person must login again after this.

A13. Delete user Admin — DELETE {{baseUrl}}/api/v1/auth/delete-user/PASTE_USER_ID

PART B — Courses

B1. All courses Public — GET {{baseUrl}}/api/v1/course/get-courses (copy a course _id)

B2. One course Public — GET {{baseUrl}}/api/v1/course/get-course/PASTE_COURSE_ID

B3. Create course Admin — POST {{baseUrl}}/api/v1/course/create-course: 
{
  "name": "Full Stack Web Dev",
  "description": "Learn React, Node and MongoDB.",
  "price": 59,
  "tags": "react, javascript, nodejs",
  "level": "beginner",
  "demoUrl": "https://www.youtube.com/embed/xyz",
  "benefits": [{ "title": "Build 5 projects" }],
  "prerequisites": [{ "title": "Basic HTML" }],
  "courseData": [{ "title": "1. React basics", "description": "Components",
    "videoUrl": "https://...", "videoSection": "Frontend", "videoLength": 42 }]
}

B4. Edit course Admin — PUT {{baseUrl}}/api/v1/course/edit-course/PASTE_COURSE_ID: { "price": 49 }

B5. Admin course list Admin — GET {{baseUrl}}/api/v1/course/get-all-course-dashboard

B6. Delete course Admin — DELETE {{baseUrl}}/api/v1/course/delete-course/PASTE_COURSE_ID

B7. Buy course Login — POST {{baseUrl}}/api/v1/order/create-order: 
{ "courseId": "PASTE_COURSE_ID", "payment_info": { "id": "pay_123", "status": "success" } }

B8. All course orders Admin — GET {{baseUrl}}/api/v1/order/get-all-order-dashboard

B9. Watch videos Login + owned — GET {{baseUrl}}/api/v1/course/get-course-content/PASTE_COURSE_ID (copy a lesson _id → your contentId)

B10. Ask question Login — PUT {{baseUrl}}/api/v1/course/add-question: 
{ "question": "What is a closure?", "courseId": "PASTE_COURSE_ID", "contentId": "PASTE_LESSON_ID" }

B11. Answer Login — PUT {{baseUrl}}/api/v1/course/add-answer: 
{ "answer": "A function with its outer scope.", "courseId": "PASTE_COURSE_ID",
  "contentId": "PASTE_LESSON_ID", "questionId": "PASTE_QUESTION_ID" }

B12. Rate course Login + owned — PUT {{baseUrl}}/api/v1/course/add-review/PASTE_COURSE_ID: 
{ "review": "Excellent!", "rating": 5 }

B13. Teacher reply Admin (spelled add-replay) — PUT {{baseUrl}}/api/v1/course/add-replay: 
{ "comment": "Thanks!", "courseId": "PASTE_COURSE_ID", "reviewId": "PASTE_REVIEW_ID" }

PART C — Marketplace (courses are digital: no address, no cart, no quantity)

C1. List courses Public — GET {{baseUrl}}/api/v1/lms/courses?page=1&limit=12 (only PUBLISHED show; copy a course _id)

C2. Categories Public — GET {{baseUrl}}/api/v1/lms/categories

C3. Search Public — GET {{baseUrl}}/api/v1/lms/search?q=react

C4. Home blocks Public — GET {{baseUrl}}/api/v1/lms/home (featured / top rated / newest)

C5. Course detail Public — GET {{baseUrl}}/api/v1/lms/courses/PASTE_COURSE_ID (locked video URLs are hidden)

C6. Curriculum Public — GET {{baseUrl}}/api/v1/lms/courses/PASTE_COURSE_ID/curriculum (each lecture has locked:true/false)

C7. Sections — GET {{baseUrl}}/api/v1/lms/courses/PASTE_COURSE_ID/sections or {{baseUrl}}/api/v1/lms/sections/PASTE_SECTION (+ /lectures suffix for the lecture list)

PART D — Lectures & access (enrollment = key)

D1. Watch preview Login — GET {{baseUrl}}/api/v1/lms/lectures/PASTE_LECTURE_ID (preview lectures open to all logged-in users)

D2. Locked lecture Login + enrolled — same URL; strangers get 403 Enroll in this course

D3. Am I allowed? — GET {{baseUrl}}/api/v1/lms/lectures/PASTE_LECTURE_ID/access → { "hasAccess": true/false }

D4. Save progress Login + enrolled — POST {{baseUrl}}/api/v1/lms/lectures/PASTE_LECTURE_ID/progress: 
{ "watchedSeconds": 120 }

D5. Complete lecture Login + enrolled — POST {{baseUrl}}/api/v1/lms/lectures/PASTE_LECTURE_ID/complete (no body). At 100% a certificate is issued automatically.

PART E — Buy course (digital checkout)

Flow: Course detail → Buy Now → payment → verify → order → enrollment → Go to Course in My Learning. No address, no quantity, no cart.

E1. Create payment Login — POST {{baseUrl}}/api/v1/lms/payments/create: 
{ "courseId": "PASTE_COURSE_ID", "couponCode": "OPTIONAL_CODE" }
Copy order.id from the reply.

E2. Verify & enroll Login — POST {{baseUrl}}/api/v1/lms/payments/verify: 
{ "razorpay_order_id": "PASTE_ORDER_ID", "razorpay_payment_id": "PASTE_PAY_ID",
  "razorpay_signature": "PASTE_SIG", "courseId": "PASTE_COURSE_ID" }
Good reply: 201 + enrollment. Bad signature → 400.

E3. My purchases Login — GET {{baseUrl}}/api/v1/lms/purchases and {{baseUrl}}/api/v1/lms/orders

E4. One order Login — GET {{baseUrl}}/api/v1/lms/orders/PASTE_ORDER_ID

PART F — My Learning (the primary dashboard; orders are just history)

F1. Dashboard Login — GET {{baseUrl}}/api/v1/lms/my-learning (continueLearning / inProgress / completed / wishlist / certificates)

F2. Enrollments Login — GET {{baseUrl}}/api/v1/lms/enrollments; one: {{baseUrl}}/api/v1/lms/enrollments/PASTE_ENROLLMENT_ID

F3. Certificates Login — GET {{baseUrl}}/api/v1/lms/certificates; one: {{baseUrl}}/api/v1/lms/certificates/PASTE_CERT_ID

PART G — Wishlist (courses)

G1. Toggle Login — POST {{baseUrl}}/api/v1/lms/wishlist: 
{ "courseId": "PASTE_COURSE_ID" }
Reply: { "wishlisted": true/false }. Alias: POST /api/v1/lms/wishlist/toggle (same body).

G2. See mine Login — GET {{baseUrl}}/api/v1/lms/wishlist

PART H — Coupons (courses)

H1. Create Admin — POST {{baseUrl}}/api/v1/lms/coupons: 
{ "code": "WELCOME10", "discountType": "percentage", "discountValue": 10, "endDate": "2027-01-01T00:00:00Z" }

H2. See all Admin — GET {{baseUrl}}/api/v1/lms/coupons

H3. Check code Login — POST {{baseUrl}}/api/v1/lms/coupons/validate: 
{ "code": "WELCOME10", "courseId": "PASTE_COURSE_ID" }
Reply: { "discount": 49.9, "payable": 449.1 }.

PART I — Reviews (courses)

I1. See reviews Public — GET {{baseUrl}}/api/v1/lms/reviews/PASTE_COURSE_ID (alias: GET /api/v1/lms/courses/PASTE_COURSE_ID/reviews)

I2. Write review Login + enrolled — POST {{baseUrl}}/api/v1/lms/reviews/PASTE_COURSE_ID: 
{ "rating": 5, "comment": "Excellent!" }
Strangers get 403.

PART J — Instructor (Instructor or Admin role)

Lifecycle: DRAFT → SUBMITTED → UNDER_REVIEW → PUBLISHED (admin) → UNPUBLISHED / ARCHIVED. Only PUBLISHED shows in the marketplace.

J1. My courses — GET {{baseUrl}}/api/v1/lms/instructor/courses

J2. Create (DRAFT) — POST {{baseUrl}}/api/v1/lms/instructor/courses: same course body as B3

J3. Edit — PUT {{baseUrl}}/api/v1/lms/instructor/courses/PASTE_COURSE_ID: { "price": 499 }

J4. Add lecture — POST {{baseUrl}}/api/v1/lms/instructor/courses/PASTE_COURSE_ID/lectures: 
{ "title": "Lesson 1", "videoSection": "Basics", "videoLength": 10, "isPreview": true }

J5. Submit for review — POST {{baseUrl}}/api/v1/lms/instructor/courses/PASTE_COURSE_ID/submit (no body)

J6. Students / revenue / analytics — GET {{baseUrl}}/api/v1/lms/instructor/students, .../revenue, .../analytics

PART K — Admin marketplace

K1. All courses (any status) — GET {{baseUrl}}/api/v1/lms/admin/courses

K2. Publish / unpublish — PUT {{baseUrl}}/api/v1/lms/admin/courses/PASTE_COURSE_ID/status: 
{ "status": "PUBLISHED" }

K3. Instructors — GET {{baseUrl}}/api/v1/lms/admin/instructors

K4. Orders / enrollments / analytics — GET {{baseUrl}}/api/v1/lms/admin/orders, .../enrollments, .../analytics

PART L — Admin extras

L1. Notifications Admin — GET {{baseUrl}}/api/v1/notifications/get-all-notification

L2. Mark read Admin — PUT {{baseUrl}}/api/v1/notifications/update-notification-status/PASTE_ID (no body)

L3–L5. Charts Admin

GET {{baseUrl}}/api/v1/analytics/users-analytics
GET {{baseUrl}}/api/v1/analytics/courses-analytics
GET {{baseUrl}}/api/v1/analytics/orders-analytics

L6. Homepage layout Public — GET {{baseUrl}}/api/v1/layout/get-layout?type=faq

SMALL letters only: banner, faq, categories. Capitals FAIL.

L7. Make/edit layout Admin — POST {{baseUrl}}/api/v1/layout/create-layout: 
{ "type": "faq", "faq": [{ "question": "Refunds?", "answer": "7 days" }] }
Edit = same body to PUT {{baseUrl}}/api/v1/layout/update-layout

PART M — Errors in plain words

You seeIt meansDo this
Invalid email or passwordEmail or password wrongRetype both
Email already existsEmail takenUse another email
Invalid activation codeWrong 6 digitsCopy again from register reply
401 UnauthorizedNot logged in / key expiredLogin again (A3)
403 ForbiddenLogged in but not adminAsk admin to do A12
You are not allowed / Enroll firstLecture is locked, no enrollmentBuy via E1–E2, then F1
Already enrolled / purchasedBought beforeOpen F1 My Learning
... does not existWrong id or CAPITAL layout typeCheck id / lowercase
404 on /product /cart /addressRemoved shop APIsUse /api/v1/lms/* instead
404 Not foundWrong id in URLCopy id again
Golden rules: IDs come from earlier replies. Enrollment = access (locked lectures need E1–E2 first). Courses are digital: no address, no quantity, no cart. Layout types are lowercase.
