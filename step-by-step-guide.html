1. How auth works (read first)

Step 1 — Register: POST /api/v1/auth/register with { name, email, password } → you get an activationToken + 6-digit activationCode (valid 5 min).
Step 2 — Activate: POST /api/v1/auth/activate-user with { activation_token, activation_code }.
Step 3 — Login: POST /api/v1/auth/login with { email, password } → returns accessToken + sets cookies.
Step 4 — Call protected routes with header Authorization: Bearer <access_token> (browsers: also works via cookies with credentials: "include").
Step 5 — Token expired? Call GET /api/v1/auth/refreshtoken (cookies sent automatically) or just login again.

user default role: shop, enroll, cart, orders, Q&A, reviews.   admin everything + manage catalog, users, orders, analytics. Promote via PUT /api/v1/auth/update-user-roles { id, role } (admin only — no self-promote).

⚠️ 401 = token missing/expired → login again. 403 = you are user on an admin-only route → get promoted, then login again.

4. Postman — step by step

  1. Create environment LMS API: baseUrl = http://localhost:8000, token = empty.
  2. Collection → Authorization → Bearer Token, value {{token}}. Every request URL = {{baseUrl}}/api/v1/....
  3. Register → Activate → Login (§2). In the Login request → Tests tab, paste this to auto-save the token: 
    const j = pm.response.json();
pm.environment.set("token", j.accessToken || j.access_token);
  4. Verify: GET {{baseUrl}}/api/v1/auth/me → should show your user + role.
  5. Shop as user: product list → address/add → cart/add → cart → coupon/apply → ecommerce/order/create (COD).
  6. Admin: login as admin (repeat step 3, overwrites token), then run §3 calls.
⚠️ Refresh endpoint GET /auth/refreshtoken needs cookies — enable Postman's cookie jar for that domain, or simply re-login.

5.2 One API client — src/api/client.js

import axios from "axios";
export const api = axios.create({
  baseURL: `${import.meta.env.VITE_API_URL}/api/v1`,
  withCredentials: true, // REQUIRED for cookie refresh
});
api.interceptors.request.use((config) => {
  const token = localStorage.getItem("accessToken");
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});
api.interceptors.response.use((r) => r, (e) => {
  if (e.response?.status === 401) {
    localStorage.removeItem("accessToken");
    if (!location.pathname.includes("/login")) location.href = "/login";
  }
  return Promise.reject(e);
});

5.3 Auth context — src/auth/AuthContext.jsx

const login = async (email, password) => {
  const { data } = await api.post("/auth/login", { email, password });
  localStorage.setItem("accessToken", data.accessToken || data.access_token);
  setUser(data.user);
  return data.user; // user.role === "admin" ? "/admin" : "/shop"
};
// register:  await api.post("/auth/register", { name, email, password });
// activate:  await api.post("/auth/activate-user", { activation_token, activation_code });
// on reload: GET /auth/me with stored token → setUser / clear bad token

7. Troubleshooting

SymptomFix
401 UnauthorizedToken missing/expired → login again; check Authorization: Bearer header.
403 ForbiddenUser token on admin route → promote via update-user-roles, login again.
Order fails, cart emptyAdd to cart first — ordering reads the server cart.
Course content blockedEnroll first via POST /order/create-order.
Activation failsCode is 6 digits, expires in 5 min; fields are activation_token + activation_code.
Email change ignoredBy design — update-user-info only updates name.
Cart delete 404Use cart item ID (/cart/item/:itemId), not product ID.
503 DB errorCheck DB_URI; Atlas must allow 0.0.0.0/0.
React CORS errorSet withCredentials: true; check VITE_API_URL has no trailing slash.

Error format

{ "success": false, "message": "Descriptive error message" }

200 OK · 201 Created · 400 Bad request · 401 Unauthorized · 403 Forbidden · 404 Not found · 500 Server error · 503 DB down
